# Tic-Tac-Toe Game

A modern and interactive Tic-Tac-Toe game built with React functional components and Hooks. It supports multiple difficulty levels (Easy, Medium, Hard), responsive layout, draw detection, and a clean UI with reset functionality.

---

## 🎮 Features

-  **Three difficulty levels**:
  - **Easy**: 3x3 grid
  - **Medium**: 4x4 grid
  - **Hard**: 5x5 grid
-  **Responsive design** – works across all screen sizes
-  **Draw detection**
-  **Winner detection**
